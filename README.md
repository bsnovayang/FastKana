# 速學五十音

用手機練習日文平假名、片假名的小網站。

👉 **線上使用：https://bsnovayang.github.io/FastKana/**

## 功能

- **學習模式**：五十音表，點假名聽發音、看易混淆字
- **輸入羅馬拼音**：看假名打拼音，打完自動判定
- **選擇羅馬拼音**：三選一，不用打字
- **聽音選字**：聽發音，三選一選出假名
- **成績與弱點**：列出最常錯的字，一鍵專門練
- 可選平假名 / 片假名 / 混合，以及要練哪幾行
- 記錄每個假名的對錯，常錯的字會多出題
- 聽音手寫、筆順動畫：開發中

## 本機執行

需要透過網頁伺服器開啟（直接開檔案無法載入 ES Modules），例如：

```
npx serve .
```
